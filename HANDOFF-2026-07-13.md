**What changed:** Rewrote `build_personal_commentary()`. Added `_extract_stat()`, `_extract_pullquote()`, `_article_tldr()`, and `_HOOK_PATTERNS`.

**How it works:**
- Extracts 3 article-specific signals: lead sentence (`extract_hook`), key stat (`_extract_stat` — regex for $, %, billion/million), pullquote (`_extract_pullquote` — blockquote or `.pullquote` class)
- 5 distinct structural patterns:
  - 0: Lead sentence drop → TL;DR → URL
  - 1: Stat first → context bridge → TL;DR → URL  
  - 2: Question framing → lead → TL;DR → URL
  - 3: Pullquote drop → attribution → TL;DR → URL
  - 4: Stakes opener → lead → TL;DR → URL
- Pattern selected by `hash(slug_from_url) % 5` — deterministic per article (crash-retry safe), varied across consecutive posts
- Dawn and Kenji paths updated to also extract real stat/hook from HTML instead of falling back to description
